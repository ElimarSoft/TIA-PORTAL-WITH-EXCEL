# TIA-PORTAL-WITH-EXCEL
This project uses Excel Worksheets to configure Structured Tia Portal SCL programs.
The main purpose is reducing the time to develop the programs in using massive Variable Data manipulation.
It uses Siemens Openness to import complete variable data from the program.
The idea is to make a simple project to demonstrate the use of sheet and VBA formulas and to propose de adequate programming techniques for highest reliability and code compactness.
